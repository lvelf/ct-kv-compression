# Stage 1 实验指南：在固定示例组中按模型反馈替换 demonstration

**交付目标**　对给定任务选出一组固定、有序的 demonstrations，构建一个 CT-KV cache，供这个任务的所有测试题复用。主指标是未见题准确率，目标是 NLP-LR 的 21 个任务等权平均相对原始 CT-KV 提升 7 个百分点。另测跨 seed 稳定性、标注量和选例成本。本轮只改变 Stage 1，沿用 dense attention、原始 CT-KV loss 和已有优化器。

**本地执行入口**　先做第 1 节的数据清单，再按第 6 节生成队列。本文是待实现的实验规格。文中 R、G 和替换候选的 runner 是本轮新增工作。已有代码与结果的参考快照是 `93dfb912c80fa2635a1499603dbd431ae9337ab8`。

## 研究假设与已有证据

1. **示例身份有效。** 固定标签配额、示例位置、shot 数及近似长度后，一次替换仍可能改变 CT-KV 最终能答对哪些题。若这种变化小于重复运行噪声，继续优化选例器的价值有限。
2. **这种差异可以提前识别。** 用单独的开发题衡量“这次替换修好了什么、又弄错了什么”，可能比纯随机搜索更能选中最终有用的示例组。正收益也应能在其他问题和不同起始组上复现。
3. **降低 seed 风险与提高均值是两个结果。** 一个策略可能只救回最差的 seeds。分别报告平均准确率、跨 seed 标准差和底部四分之一的平均准确率。
4. **标签偏移是一个可能机制。** Boolean 上，更新可能把预测推向示例多数类。某些 NLP-LR 分类任务中，更新预测分布本身有益。测更新前后的伤害与修复，不预设统一的理想预测比例。

已有 21 任务结果中，A200 为随机选例、200 步原始 CT-KV，准确率 54.52%。D50 为原有 Stage 1 选例、原始更新至第 50 步，准确率 55.78%。等步数 D50 − A50 为 +1.00 点，95% 配对区间 [+0.05, +2.00]，分类约 +1.70，多选约 0。另一次从 30 组中按 20 道开发题的正确答案 NLL 选组，第 0 步及第 50 步选出的组在终点的平均任务分数为 44.38 和 44.41，预定随机组为 43.57。该研究的任务分数混合了分类 macro-F1 和多选准确率，应单独解读。双 cache 的 +9.99 点来自用每道测试题的真实答案挑 cache，只作为逐题互补性的历史诊断。[Round 2 报告](../../results/ctkv_accuracy_round2/REPORT.md) · [早期选例实验 E3/E4](../../results/ctkv_accuracy_study/nlp_lr/REPORT_nlp_lr.md)

## 1. 冻结数据、预算和运行条件

- 每个任务预先划分四组 ID：**P** 提供 demonstrations 并拟合现有分布特征，**Q** 提供逐题反馈以生成或筛选候选，**V** 在入围组及原组中选最终组，**T** 只做策略冻结后的最终评测。Q/V 是额外的带标签开发数据。模型更新始终只用该组的 k 条 demonstrations。使用原始 ID 与规范化输入哈希排查跨组重复，同源改写按源 ID 成组划分。所有实验臂共享 P/Q/V/T，dev 题不写入 demo cache。对每次取标签记录用途。
- 默认从既有非测试 support pool 确定性划 Q/V。对去重后的 N 条，各取 `min(12, floor(0.20 × N))` 条，其余归 P。固定分割种子 20261128，所有 demonstration seeds 共用。固定标签任务按原池类别比例近似分层，并优先让 P 保有原类别；多选按题抽，不按正确选项的字母分层。如某类样本太少无法覆盖所有分区，报告实际计数。发现 T 与非测试池重叠时从非测试池移除重复项，再按冻结规则拆分。若 Q 或 V 少于 4，或 P 装不下 k 条加一个合法替换，用 D 回退并记录原因。该阈值仅用于本轮可行性，不代表 4 道题足以可靠选组。
- 从 P **重新生成** A（随机）和 D（仓库中 32 组候选里选特征均值最接近数据池的一组）。旧 A/D 若含 Q/V 题，只用于历史复现。记录 P 总标签数、实际访问的标签 ID 并集、Q/V 数、最终部署 shots。将“从已有带标签池选 k 条”的结果与严格总共只给 k 条标签的设定分开报告；后者若无独立带标签开发题，仅运行可用的既有基线。
- NLP-LR 主面板沿用 GPT-2 Large、16-shot、10 组 demonstration seeds 1000–1009、optimizer seed 0、原始 200 步 cosine schedule，在第 50 步取 checkpoint；A200 跑到 200 步。BBH Boolean 使用原有 Llama-3-8B-Instruct、10-shot、20 个 seeds 1000–1019、终点 16 步及原预测解析器。不同任务复用同一选例规则，shot 数和更新步数由其基线协议提供。
- 固定模型版本、提示模板、tokenizer、前缀与选项截断、打分精度、答案并列处理和可评测题 ID。每次换示例都从原模型重新构建该组 prefix cache，重置优化器与 RNG。缓存可按“任务、示例有序 ID、模型、配置、更新步数”的完整键复用，记录命中。沿用历史面板 T 时，把结果标为已反复评估面板上的新对比；真正独立的确认使用此前未看过的题或任务。

## 2. 生成严格配对的单次替换

从每个 task × seed 的 D 起步。均匀无放回抽 4 个可替换位置，每个位置最多提出 4 条候选。位置和候选用 task、seed、位置及独立 salt 的稳定哈希抽取，先生成清单再看模型分数。每个方案只换原位的一条，保留其余 k−1 条的 ID 与顺序。保留原始 D 作为“不换”的选项。

| 输出格式 | 可以换入的示例 | 如何测模型反馈 |
|---|---|---|
| 所有题共享语义标签（含 Boolean） | P 内未被该组使用、标签相同的示例 | 对该题所有合法标签打分。Boolean 附加 True/False 分方向统计 |
| 选项随题变化 | P 内未被使用、选项数相同的示例。使用各题自己的选项文本和原顺序 | 在每题内部比较正确项和最强干扰项。A/B/C/D 不作为跨题类别 |
| 开放生成 | 若有确定的逐题任务评分器，可用其分数差记录修复与损失 | 单列为探索。若无可复现的评分器，输出 D 并记录原因 |

在上述约束内优先同一 token 长度四分位桶，不足时按相邻桶距离依次补充，并记录放宽次数。同一位置的同一候选只计一次，过滤与组内示例同源的候选。按替换后完整组检查 token 预算和截断，排除会截掉完整示例或答案的方案。合法方案不足时全部使用，各臂共享同一清单和实际额度。保存旧/新 ID、位置、标签或选项数、token 长度、四分位桶及 D 的特征距离变化。

## 3. 给替换打分，并测它能否跨过梯度更新

对开发题 j，用仓库原 evaluator 的选项分数 s（越大越好，NLP-LR 取原有长度归一化选项 loss 的负值）。定义正确答案相对最强错误答案的 margin：

    m_t(S,j) = s_t(S,j,gold) − max_{a≠gold} s_t(S,j,a)
    v_t(c,j) = m_t(S_c,j) − m_t(D,j)

这里 c 是一次原位替换，S_c 是换后的完整组，t 是 CT-KV 更新步数。最终对错按原 evaluator 判定。BBH 若主评测使用生成解析，则 True/False 的 forced-choice margin 只用于候选排序，最终准确率和对错翻转仍来自原解码。报告代理打分与原解码的一致率。单独保存从错到对（fixed）、从对到错（broken）、净修复 fixed − broken，以及仍然都错的题数。遇到多正确答案时使用原任务认可的答案集合；只有一个合法选项或无有效 gold 的题不用于 margin，单列覆盖率。

**先验证排序。** 在小面板上，对全部合法候选及 D 都保存第 0 步、一个早期 checkpoint（NLP-LR 第 10 步，BBH 第 4 步）和原终点 t*（50 或 16）。逐 task × seed 计算 Q 上的早期排序与 V 上终点准确率增量的 Spearman 相关、早期 top-4 的终点均值相对随机四组期望值的差（均匀随机抽取时，该期望等于全部合法候选的均值）、以及最终挑中原组的频率。并列用平均秩，常数列相关记为未定义并报告数目。Q 与 V 分开使“跨步数变化”和“换一批题就失效”都反映在实际可用性中；另报同一 Q 上跨步数的相关，帮助解释失败原因。小面板用于选择全局筛选步数，不触碰 T。

**入围规则 G。** 第一名取 Q 上平均 `clip(v_t, −1, 1)` 最大的候选；后续名额按对开发题的作用是否互补贪心选择。令已入围候选对题 j 的最好正向增量为 `b_j = max(0, 已选候选的 clip(v_t))`。一个新候选的得分为各题 `max(0, clip(v_t) − b_j) + min(0, clip(v_t))` 的均值，clip 均为 [−1,1]。每次加入得分最高者并更新 b。这样，帮助不同题的候选有机会入围，把原先做对的题拖差仍有代价。固定最多 4 个入围名额，并列按事先记录的哈希打破。**入围的四组是四个替代方案。部署时只从中选一组。** 开放任务如采用二值任务分数，直接使用配对分数差，并标明打分口径。

**最终选组。** 对入围方案及原 D 分别运行至 t*，在 V 按任务准确率选出一个。平局优先原 D，其余用固定哈希。所有有搜索的臂使用相同规则。保存每题 margin 和正确性，便于单独核查“只提高正确答案概率，但干扰项涨得更多”等情况。此处 margin 只服务于选例，CT-KV 的训练目标保持原始实现。

## 4. 对照与归因

| 实验臂 | 做法 | 回答的问题 |
|---|---|---|
| A0 / A50 / A200 | 同一随机示例组的 ICL、50 步和原始 200 步 CT-KV。BBH 用 A0/A16 | 相对原始 ICL 和 CT-KV 的实际准确率 |
| D0 / D50 | 同一分布匹配组的 ICL 及更新终点。BBH 对应 D0/D16 | 已有 Stage 1 基线 |
| R，随机搜索 | 从共享清单等概率挑最多 4 个方案，在 V 上与 D 一起选 | 多试几组本身能带来多少收益 |
| M，按平均影响选 | 共享清单按 Q 上平均 clipped margin 增量取前 4，再在 V 上与 D 一起选 | 逐题影响信号能否优于随机 |
| G，按平均影响和互补性选 | 使用第 3 节的完整规则 | 挑作用互补的候选是否额外改善最终准确率 |

主要比较 **G − R**（同候选数、同终点评估次数）、**G − D**（相对已有 Stage 1）及 **G − A200**（7 点目标）。M − R 和 G − M 定位收益来源。对最终选中的同一组再读取其第 0 步预测，同时报告 `(G终点 − D终点) − (G0 − D0)`，分辨 ICL 起点改善与梯度更新收益改变。每个臂独立记录训练/验证标签数、打分、建 cache、更新、读出、实际 GPU 秒及峰值显存。R 不需要计算全部早期反馈。除相同终点名额外，在 pilot 测出实际时间后，再预先固定一个**等 GPU 秒**的 R 对照，把节省的筛选时间用于额外随机候选。用 pilot 的 G 总秒数减去 R 的固定开销，除以每个随机候选的适应与验证中位秒数，向下取整，按共享清单的合法候选数封顶；各任务使用相同的换算规则并公布预算和实耗。另报最终单 cache 的部署成本，避免与离线搜索时间混在一起。

## 5. 稳定性、标签偏移与后续实验

- **跨搭档复现（CondAcc 启发）。** 在 pilot 预先选取同一任务的两个不同 D 作为搭档背景。对两组共有合法替换候选的同一标签或选项数层比较贡献，每组都与自己的原组作差。要求被换出的条目在两组内满足相同配额、长度规则，尽量匹配插入位置并记录。报告同一候选在两组的净修复同号率、相关、可配对数，同号率以置换候选身份作参照。回退、并列或缺少配对如实记录。若出现可复现信号，再加一个在两个背景上平均效果后入围的实验臂，并为 R 匹配额外计算量。
- **Boolean 的偏移。** 对固定标签配额的 D、R、G 同时记录 ICL 与更新后预测 True 比例、True/False 的 recall、各标签的 fixed/broken，以及真实标签占比。主检验是在完全相同的 demo 标签计数下，G 是否减少多数类方向的有害翻转并提高准确率。原报告的平衡配额臂 B 可作机制参照。固定配额的单替换无法估计“改变配额”的因果效应；若需要检验比例本身，再单列相同预算和长度下的偏斜/平衡配额实验。[原 Boolean 结果](../../results/ctkv_refinement/REPORT_results.md)
- **下一轮的组合搜索。** 只有当单次替换的优势在独立题目上可复现时，再对前两组各尝试第二处位置替换，重新计算整组逐题反馈并适应。保留单替换及不换两种选择，随机搜索获得相同分支预算。固定示例身份只置换顺序可作为单独消融。完整影响向量 DPP 也可作为后续入围器，与 G 共用影响矩阵、V 和更新预算。

## 6. 队列、停止条件与报告

1. **CPU 清单 → GPU smoke。** 复用[通用 selector](../../context-tuning/refinement/refine.py)与[数据适配](../../context-tuning/refinement/benchmark_plan.py)。在新结果目录 `results/ctkv_stage1_conditional_swaps/` 写入 `PLAN.md`、split/seed 哈希、示例有序 ID、每组实际预算及实现 commit。复用[Round 2 的调度配置](../../context-tuning/round2_jobs.py)及[选项打分代码](../../context-tuning/round2_nlplr.py)，给 scorer 增加显式的 Q/V 输入；筛选 worker 只读相应清单。用一个分类任务、一个多选任务做 smoke：相同输入求差为零，单替换只动一个位置，基线预测能复现，筛选阶段没有 T 记录。对同一组做重复适应以估计终点噪声。
2. **Pilot。** NLP-LR 预定用 `financial_phrasebank`、`sick`、`qasc`、`openbookqa`，seeds 1000–1002；另跑 BBH Boolean 的相同 3 个 seeds 作为跨模型检查。每单位最多 16 个替换加原组，至多 255 个适应轨迹，多个 checkpoint 共享同一轨迹；跨背景诊断和基线复现另记。四个 NLP-LR 任务覆盖不同的已知响应，只用于诊断。在 V 上对步数 0/早期分别计算“Q 选出的 G 前四组”相对随机四组的终点准确率均值增量，先平均 seed 再等权平均任务。若合法候选不超过四组，两策略在该单位入围同一全集，增量记零。若第 0 步增量为正，选第 0 步；否则若早期步为正，选早期步；两者均无正信号则停在 pilot，报告原组、等预算随机搜索及噪声。NLP-LR 与 BBH 分协议作决定，不逐任务挑步数。记录区间与两种步数的全表；此门槛只决定是否花费全队列算力。
3. **冻结 → 正式队列。** 运行前锁定候选预算、筛选步数、tie-break、T 题目清单、计算时间预算和模型版本。先将 A、D、R、M、G 的最终示例组逐一锁定，随后运行 T evaluator，每个 task × seed × arm 只评这个已选组。NLP-LR 跑通 21 任务 × 10 seeds，BBH 按自己的 pilot 决定是否扩到 20 seeds，独立报告。额外给出排除四个 pilot 任务后的 NLP-LR 结果。若只能使用历史 T，明确新任务泛化还待确认。
4. **统计与决定。** 每个任务内先平均 seeds，然后对任务等权，分别列出全体 21 任务、12 分类、9 多选及单项任务。用 5,000 次配对 bootstrap 在任务内重抽 seeds 与题 ID；每个重抽的题 ID 对该任务所有 seed/臂相同，保持两者的交叉结构。区间解释为对这张固定面板的区间，BBH 单列。报告 95% 区间、跨 seed SD、最差四分之一 seeds 的均值（取 ceil(n/4) 个）、留一任务敏感性、fixed/broken、有效覆盖、回退率和时间。另列 +7 点目标的点估计与区间下界。G 若只超过 D 而与 R 持平，收益归于搜索；若只改善低分 seeds，结论写稳定性收益；G − M 若接近零，保留更简单的 M。
5. **交付。** `PLAN.md`、`splits.json`、`candidates.jsonl`、`scores_dev.jsonl`、`locked_selections.jsonl`、`predictions_test.jsonl.gz`、`timing.csv` 和 `REPORT.md`。报告列出预期/完成/失败/回退的单位数及原因。作业 ID 由任务、seed、有序示例 ID、模型和配置生成；重复入队复用已完成产物，配置不一致时另建输出。报告首页直接回答三件事：未见题准确率提高了多少、能否超过等预算随机搜索、离线代价是多少。

## 方法出处

- LENS 借鉴整组替换与搜索。其 Table 5 将单例筛选和加入搜索分开，实验对象是普通 ICL。[Li & Qiu, Finding Support Examples for In-Context Learning](https://aclanthology.org/2023.findings-emnlp.411/)
- 两阶段 DPP 借鉴逐题影响向量和作用互补性。本文的贪心入围是面向小候选池的改法。[Yang et al., Representative Demonstration Selection for In-Context Learning with Two-Stage Determinantal Point Process](https://aclanthology.org/2023.emnlp-main.331/)
- CondAcc 借鉴多次改变搭档后估计示例效用，并测跨 seed 稳定性。原实验从精选池里随机抽提示。[Chang & Jia, Data Curation Alone Can Stabilize In-context Learning](https://aclanthology.org/2023.acl-long.452/)
